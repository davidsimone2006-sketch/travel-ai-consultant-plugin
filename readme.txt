== Description ==

Alex is a premium AI-powered travel consultant plugin for WordPress. It provides an immersive 3D interface where customers can chat with an intelligent AI advisor about their travel needs - flights, hotels, cruises, vacation packages, and Amtrak train bookings.

**Key Features:**

- 🤖 **Intelligent AI Conversation** - Powered by OpenAI's GPT technology
- 🎨 **Luxury Gold Premium UI** - Beautiful 3D immersive interface
- 🏨 **Multiple Travel Services** - Flights, Hotels, Cruises, Packages, Amtrak
- 💰 **Budget-Friendly Recommendations** - AI focuses on best value for money
- 📧 **Automatic Lead Capture** - Leads sent to your email with conversation summary
- 📊 **Admin Dashboard** - Manage and track all leads in WordPress
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🔒 **Secure & Private** - All data encrypted and GDPR compliant
- ⚙️ **Easy Installation** - Simple shortcode placement

**How It Works:**

1. Users interact with Alex (AI consultant) in a beautiful 3D chat interface
2. Alex asks intelligent questions about destination, budget, dates, and preferences
3. AI extracts travel details and displays them in a side panel
4. When customer is ready, they submit their inquiry with contact details
5. Lead is automatically emailed to you with full conversation context
6. Customer receives confirmation email
7. Your team manually reviews and provides best offers

**Perfect For:**

- Travel agencies and portals
- Tour operators
- Flight booking platforms
- Hotel chains and resorts
- Cruise companies
- Vacation package sellers

== Installation ==

1. Download the plugin files
2. Upload to `/wp-content/plugins/travel-ai-consultant-plugin/`
3. Activate the plugin through the 'Plugins' menu in WordPress
4. Go to 'Alex Consultant' → 'Settings'
5. Add your OpenAI API key (get it from https://platform.openai.com/api-keys)
6. Configure your email and consultant name
7. Use shortcode `[alex_travel_consultant]` on any page or post
8. Leads will be sent to your configured email address

== Usage ==

**Display the Consultant:**
```
[alex_travel_consultant]
```

**In a dedicated page:**
1. Create a new page titled "Talk to Alex"
2. Add the shortcode `[alex_travel_consultant]` to the page
3. Publish
4. Users can now access your AI consultant from that page

**Configure Settings:**
1. Go to WordPress admin
2. Navigate to 'Alex Consultant' → 'Settings'
3. Set your consultant name and title
4. Add your OpenAI API key
5. Update your email address for lead notifications
6. Save settings

== Frequently Asked Questions ==

**Q: Do I need an OpenAI account?**
A: Yes, you need an OpenAI API key. Sign up for free at https://platform.openai.com and get your API key from the API keys section. You'll have free credits to start.

**Q: How much does it cost?**
A: OpenAI API usage is pay-as-you-go. Each conversation typically costs less than $0.01. The plugin itself is free with an MIT license.

**Q: Can I customize the consultant's name and appearance?**
A: Yes! Go to Settings and change the consultant name and title. You can also customize colors through CSS.

**Q: Where are the leads stored?**
A: Leads are stored in your WordPress database and also emailed to your configured email address. You can view all leads in the WordPress admin dashboard.

**Q: Is it GDPR compliant?**
A: Yes, the plugin includes privacy and data protection measures. Make sure to add a privacy policy disclosure on your website.

**Q: Can it handle multiple languages?**
A: The plugin currently supports English. The AI can understand and respond to multiple languages through OpenAI's capabilities.

**Q: What if I want to integrate with real booking systems?**
A: Currently, it's designed for lead capture and manual booking by your team. Future versions can integrate with Amadeus, Sabre, and other GDS APIs.
