## 🚀 Quick Start with Groq (5 Minutes)

### Step 1: Get Free Groq API Key

1. Go to: **https://console.groq.com**
2. Click **"Sign Up"** (completely FREE)
3. No credit card needed!
4. Verify your email
5. Go to **"API Keys"** section
6. Click **"Create API Key"**
7. Copy the key

### Step 2: Install Plugin

1. Upload plugin to WordPress
2. Activate plugin
3. Go to **WordPress Admin → Alex Consultant → Settings**
4. Paste your Groq API key
5. Fill in your email
6. Click **Save Settings**

### Step 3: Add to Your Website

```
[alex_travel_consultant]
```

### Step 4: Done! ✅

Your AI consultant is live with ZERO costs!
