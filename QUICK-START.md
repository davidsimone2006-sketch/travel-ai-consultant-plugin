## 🚀 Installation Steps (5 Minutes)

### Step 1: Download Plugin
1. Download all files from GitHub repository
2. Create a folder: `travel-ai-consultant-plugin`
3. Place all files inside this folder

### Step 2: Upload to WordPress
1. Go to your WordPress Admin
2. Navigate to: **Plugins → Add New**
3. Click: **Upload Plugin**
4. Select the plugin folder (or ZIP file)
5. Click: **Install Now**
6. Click: **Activate Plugin**

### Step 3: Get OpenAI API Key (2 Minutes)
1. Visit: https://platform.openai.com/api-keys
2. Sign up for free (if needed)
3. Click: **Create new secret key**
4. Copy the key (keep it safe!)

### Step 4: Configure Plugin (3 Minutes)
1. Go to: **WordPress Admin → Alex Consultant → Settings**
2. Fill in these fields:
   - **Consultant Name**: Alex
   - **Consultant Title**: Senior Travel Advisor
   - **Admin Email**: david.simone2006@gmail.com ← YOUR EMAIL
   - **OpenAI API Key**: Paste your API key here
3. Click: **Save Settings** ✅

### Step 5: Add to Your Website (1 Minute)

**Option A: Add to Existing Page**
1. Edit any page/post
2. Add shortcode: `[alex_travel_consultant]`
3. Publish ✅

**Option B: Create Dedicated Page**
1. Create new page: **Pages → Add New**
2. Title: "Chat with Alex - Your Travel Advisor"
3. Add shortcode: `[alex_travel_consultant]`
4. Publish ✅

## 🆘 Troubleshooting

### Issue: "Consultant not showing on page"
**Solution:**
- Verify shortcode is added: `[alex_travel_consultant]`
- Check plugin is activated
- Clear browser cache
- Try different page

### Issue: "API key error"
**Solution:**
- Go to https://platform.openai.com/api-keys
- Generate new API key
- Paste exact key (no spaces)
- Save settings

### Issue: "Emails not received"
**Solution:**
- Verify email in settings is correct
- Check spam/junk folder
- Test by submitting lead
- Check WordPress email configuration

### Issue: "AI not responding"
**Solution:**
- Validate OpenAI API key
- Check API quota/credits
- Verify internet connection
- Check browser console for errors
- Try in different browser
