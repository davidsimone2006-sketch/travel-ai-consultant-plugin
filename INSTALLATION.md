# Alex Travel Consultant - Complete Installation & Setup Guide

## 📋 Overview

Alex is a premium AI-powered travel consultant plugin that transforms your WordPress travel portal into an intelligent booking platform. This guide will help you set up everything in under 30 minutes.

## 🚀 Quick Start (5 Minutes)

### Step 1: Install Plugin

1. **Download the plugin package** from the repository
2. **Upload to WordPress:**
   - Go to WordPress Admin → Plugins → Add New
   - Click "Upload Plugin"
   - Select the plugin ZIP file
   - Click "Install Now"
3. **Activate:** Click "Activate Plugin"
4. You'll see "Alex Consultant" in the left sidebar

### Step 2: Get OpenAI API Key (2 Minutes)

1. Go to https://platform.openai.com/api-keys
2. Sign up for free (if you don't have an account)
3. Click "Create new secret key"
4. Copy the key (you'll need this next)

### Step 3: Configure Plugin (3 Minutes)

1. Go to **WordPress Admin → Alex Consultant → Settings**
2. Fill in these fields:
   - **Consultant Name:** Alex (or your preferred name)
   - **Consultant Title:** Senior Travel Advisor
   - **Admin Email:** david.simone2006@gmail.com (your email)
   - **OpenAI API Key:** Paste your API key from Step 2
3. Click **Save Settings**

### Step 4: Add to Your Website (1 Minute)

**Option A: Add to Existing Page**
1. Edit any page/post in WordPress
2. Add this shortcode: `[alex_travel_consultant]`
3. Publish/Update
4. Done! ✅

**Option B: Create Dedicated Page**
1. Go to **WordPress → Pages → Add New**
2. Title: "Talk to Alex - Your Travel Advisor"
3. Add shortcode: `[alex_travel_consultant]`
4. Publish
5. Share the page link with customers

## 🐛 Troubleshooting

### Issue: "Invalid API Key"
**Solution:**
1. Go to https://platform.openai.com/api-keys
2. Verify your API key is active
3. Paste the EXACT key (no extra spaces)
4. Save settings again

### Issue: "Consultant not appearing on page"
**Solution:**
1. Verify shortcode is added: `[alex_travel_consultant]`
2. Check if plugin is activated
3. Clear WordPress cache
4. Try in different browser

### Issue: "Emails not received"
**Solution:**
1. Check email in Settings is correct
2. Check spam/junk folder
3. Verify WordPress can send emails
4. Test by submitting a lead

### Issue: "Chat not responding"
**Solution:**
1. Check OpenAI API key is valid
2. Verify API has credits
3. Check API usage at openai.com
4. Try refreshing the page
